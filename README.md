# Проект "Банковский виджет"

## Описание:

Проект "Банковский виджет" - это функционал, который принимает на входе от пользователя номер карты и счета и выводит его маску, так же выводит тип карты или счета и маску, меняет формат введенный пользователем даты, фильтрует списки со словарями и сортирует словари по убыванию даты.
pyproject.toml — главный конфигурационный файл проекта:

зависимости (основные и для разработки);

настройки инструментов линтинга (flake8, black, isort, mypy);

конфигурация pytest.

README.md — файл с описанием проекта (рекомендуется создать для документирования).

Директория src/ Содержит исходный код приложения:

init.py — делает директорию src пакетом Python.

masks.py — реализует базовые функции маскировки:

get_mask_card_number(card_number: str) -> str — маскирует номер карты в формате XXXX XX** **** XXXX;

get_mask_account(account_number: str) -> str — маскирует номер счёта в формате **XXXX.

widget.py — новый модуль с расширенными функциями:

mask_account_card(input_string: str) -> str — обрабатывает строки вида "Visa Platinum 7000792289606361" или "Счёт 73654108430135874305", вызывает соответствующие функции маскировки из masks.py;

get_date(date_string: str) -> str — преобразует дату из формата ISO ("2024-03-11T02:26:18.671407") в формат "ДД.ММ.ГГГГ" ("11.03.2024").

generators.py — содержит функции для работы с массивами транзакций:

filter_by_currency - принимает на вход список словарей, представляющих транзакции.

transaction_descriptions - принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.

card_number_generator - выдает номера банковских карт в формате XXXX XXXX XXXX XXXX, где X — цифра номера карты. Генератор может сгенерировать номера карт в заданном диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.

## Тестирование

Тесты созданы в пакете tests. Модуля в пакете tests содержат тесты для каждой функции.
Название модуля теста соответствует модулю функционального кода с префиксом test.
То есть, в модуле test_masks.py содержаться тесты для функций модуля masks.py и так далее.
Для тестирования был установлен фреймворк тестирования pytest и добавлена библиотека pytest-cov.
Запуск тестов: команда pytest --cov в терминале.
Code coverage — это метрика, которая показывает, какой процент кода программы был протестирован.
Чтобы запустить тесты с оценкой покрытия, можно воспользоваться командой: pytest --cov=src --cov-report=html
Отчет будет сгенерирован в папке htmlcov и храниться в файле с названием index.html
